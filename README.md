# Cool Shot Systems - Template Gallery

Welcome to the official collection of code templates from Cool Shot Systems. Our goal is to provide high-quality, well-documented starter kits to help you build better projects, faster.

All templates are open-source and free to use.

## How to Use These Templates

Each repository is a **GitHub Template**.
1.  Click on the template you want to use.
2.  Click the green "**Use this template**" button on that repository's page.
3.  Choose "**Create a new repository**".
4.  This will create a new repository in your own account, copying all the files and folders for you to customize.
